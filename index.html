Etiquetas de autocierre by Aitor

<meta>

La etiqueta meta proporciona metadatos sobre el documento HTML. Sirve para definir el juego de caracteres (charset), configurar la vista responsive para dispositivos móviles (viewport) y ofrecer una descripción que leen los buscadores.

<link>

Sirve para vincular documentos externos con el archivo HTML actual, como por ejemplo la hoja de estilos CSS que le da formato a esta página.

<br>

Esta etiqueta produce un salto de línea dentro de un bloque de texto.
Aquí hay un salto de línea en mitad de la frase para demostrar su funcionamiento.

<hr>

Representa un cambio temático entre párrafos o bloques de contenido, dibujando una línea horizontal para separarlos visualmente.

<img>

Se utiliza para incrustar o mostrar imágenes dentro de la página web mediante la ruta especificada en su atributo src.

<input>

Permite crear campos interactivos dentro de formularios para que los usuarios puedan introducir información o datos de texto.

¿Crees que esto es mucho texto?

<col>

Permite definir propiedades o estilos específicos para columnas individuales dentro de una tabla definida mediante colgroup.

<embed>

Sirve para integrar aplicaciones externas o contenidos interactivos dentro del documento HTML, como archivos PDF o plugins multimedia.

<param>

Sirve para pasar parámetros de configuración a un objeto incrustado mediante la etiqueta object. Actualmente es una etiqueta en desuso que los navegadores ignoran, por lo que no causa un efecto visible.

<source>

Se utiliza dentro de elementos multimedia como video o audio para especificar múltiples recursos o formatos de archivo compatibles.

<wbr>

Indica una posición dentro del texto donde el navegador puede realizar un salto de línea opcional si el espacio disponible en la pantalla no es suficiente para la palabra completa.
